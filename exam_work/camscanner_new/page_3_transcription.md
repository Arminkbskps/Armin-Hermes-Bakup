**توضیح در مورد اشکال بالای کادر:**

### **متن سوال:**

**۲-** دو تا از زاویه‌های مثلثی $x + ۲۰^\circ$ و $۳x - ۱۵^\circ$ هستند. حدود $x$ کدام باشد تا ارتفاع‌های این مثلث، در نقطه‌ای درون آن همرس باشند؟

**گزینه‌ها:**

۱) $۵^\circ < x < ۳۵^\circ$

۲) $۲۱٫۲۵^\circ < x < ۳۵^\circ$

۳) $۳۵^\circ < x < ۴۳٫۷۵^\circ$

۴) $۲۱٫۲۵^\circ < x < ۴۳٫۷۵^\circ$
